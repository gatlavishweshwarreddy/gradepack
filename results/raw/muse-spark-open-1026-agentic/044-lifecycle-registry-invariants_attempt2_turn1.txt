"""
LifecycleRegistry manages resources with strict lifecycle invariants.

Registry lifecycle:
  CREATED -> OPEN -> CLOSED
  - new registry starts as CREATED
  - open() moves to OPEN
  - close() moves to CLOSED (terminal, cannot be reopened)
  - any operation requiring OPEN must raise RegistryClosed if not OPEN
  - public attributes: state (str), is_closed (bool)

Resource lifecycle (per id):
  PENDING -> ACTIVE -> SUSPENDED -> ACTIVE -> FAILED -> DISPOSED
  Transitions:
    register(id, data=None): creates PENDING, fails if duplicate id
    initialize(id): PENDING -> ACTIVE
    suspend(id): ACTIVE -> SUSPENDED, must raise InvalidTransition if already SUSPENDED
    resume(id): SUSPENDED -> ACTIVE, must raise InvalidTransition if not SUSPENDED
    fail(id): PENDING/ACTIVE/SUSPENDED -> FAILED
    dispose(id): PENDING/ACTIVE/SUSPENDED/FAILED -> DISPOSED, requires ref_count==0 else ResourceInUse
    DISPOSED is terminal for all operations

Reference counting:
  acquire(id): increments ref_count, allowed only on ACTIVE/SUSPENDED, raises InvalidTransition on DISPOSED/FAILED/PENDING
  release(id): decrements, raises if count would go negative
  get_refcount(id): returns current count
  dispose requires ref_count==0

Data access:
  get(id): returns stored data, allowed only on ACTIVE/SUSPENDED, raises InvalidTransition otherwise, must be O(1)
  put(id, data): sets data, allowed only on ACTIVE, must be O(1)
  lookup_steps: public counter incremented per internal lookup step, must stay O(1) per get/put (1 step per op)

Close semantics:
  close() must transition every non-DISPOSED resource to DISPOSED.
  If any resource has ref_count>0, close() must raise ResourceInUse and leave registry OPEN (not CLOSED).
  After successful close, every resource must report DISPOSED via get_resource_state.

Context managers:
  Registry as context manager: __enter__ opens if needed, __exit__ closes (never suppresses exceptions)
  session(id): context manager that does acquire on enter and release on exit, correctly handling exceptions

Other public API:
  get_resource_state(id) -> str
  list_resources() -> list of ids
"""
